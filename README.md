<h1 align="center">搭子AI (aiDazi)</h1>

**将你最喜欢的角色带入现实！**

搭子AI是一款使用 Flutter 构建的、注重隐私的开源 AI 伙伴应用。全链路国产化 API：大语言模型对话、角色专属语音（复刻或文字设计）、文生图、文生视频，四项能力各自独立配置 API Key / 接口地址 / 模型名，可全部使用阿里云百炼一个 Key 打通。

## ✨ 核心功能

- **🤖 智能聊天:** 支持阿里千问（**推荐**）、DeepSeek、火山引擎豆包、智谱 GLM、Kimi 及任意自定义 OpenAI 兼容端点；当前日期时间自动注入对话，回复更有场景感
- **🎭 角色管理:** 创建、编辑 AI 角色；兼容 SillyTavern V2 角色卡（`aiDaziCard_*.png`）；支持性格特质 0-10 强度设定；导入导出统一走局域网配置网页
- **📖 故事库:** 故事池管理（新增故事、切换当前故事、一键为当前故事生成背景图），故事导入支持文件导入与直接输入两种方式（局域网网页）
- **🔊 角色专属语音:** 阿里百炼 CosyVoice 模型，两种创建方式——上传公网参考音频 URL 复刻音色，或用一段自然语言描述设计全新音色；无音色时自动回落男女声；开启「自动发声」后 AI 回复自动播报
- **🎨 文生图:** 阿里万相（默认），支持参考图保持角色一致性；长按消息即可 画图 / 视频 / 灵感，也可基于选中消息一键生成配图；9:16 竖屏适配
- **🎬 文生视频:** 阿里万相（默认）/ 火山 Seedance / 可灵 / MiniMax，支持用户自定义提示词
- **🖼️ 自动换背景:** 每个角色拥有专属背景图库，开启自动背景后每 2-5 次对话自动轮换；背景图自动下载到本地，重启后恢复
- **📁 媒体库:** 按角色浏览、预览、删除所有生成的图片与视频，角色之间严格隔离
- **💾 本地备份与恢复:** 所有数据保存在设备本地；聊天记录可保存/提取为本地 JSON 文件
- **🔒 隐私优先:** 所有数据存储在你的设备上，本应用不收集任何个人信息

## ⚙️ 配置方式：局域网网页

App 内不出现任何手动输入 API Key 的界面。**密钥配置**、**角色卡**导入导出、**故事**导入导出全部通过局域网网页完成：

1. App 内置 HTTP 服务，默认端口 `8888`（占用自动顺延 8889/8890）
2. 在设置中启动后，App 显示 `http://192.168.x.x:8888`，同一 WiFi 下用电脑浏览器打开
3. 网页四张卡片（文字 LLM / 语音 TTS / 图像 / 视频）各自填写 **API Key + 接口地址 + 模型名** 三要素，全部可独立指向任意 OpenAI 兼容服务
4. 保存成功后服务自动关闭；空置 10 分钟无操作也会自动关闭

## 🚀 快速开始

1. 注册阿里云账号并开通[百炼大模型服务](https://bailian.console.aliyun.com/?tab=model#/api-key)，获取 API Key
2. 打开应用，欢迎页面会提示「本软件基于阿里百炼模型设计，需先配置 qwen 模型才能正常使用」
3. 进入 **设置 → 模型配置**，点击「网页配置」启动内置服务，用同 WiFi 的浏览器粘贴 API 密钥
4. 本软件基于阿里模型设计，**推荐优先选择 qwen 模型**（对话 `qwen` / 语音 `cosyvoice-v3-flash` / 图像 `wan2.7-image` / 视频 `wan2.7-t2v`，默认地址均为 dashscope，一个百炼 Key 可填满全部四项）
5. 回到聊天页，从屏幕顶部就是背景与对话，点输入框右侧「+」可展开工具菜单（自动背景 / 自动发声 / 全屏 / 保存聊天 / 提取聊天 / 新聊天）

## 🛠️ 构建

```sh
git clone <仓库地址>
cd aiDazi
flutter pub get
flutter run
```

打包：

```sh
flutter build apk      # Android
flutter build web      # Web
flutter build windows  # Windows
```

> Web 构建因浏览器安全限制，保留手动输入 API Key 与本地导入角色入口。
